Kebijakan Privasi

Terakhir diperbarui: 20 Mei 2024

1. Informasi Umum

Selamat datang di MurajaahQu. Kami sangat menghargai privasi Anda. Kebijakan ini menjelaskan bagaimana kami mengelola informasi di dalam aplikasi ini.

2. Penyimpanan Data

Aplikasi MurajaahQu dirancang untuk bekerja secara lokal. Data hafalan, progres murajaah, dan pengaturan pribadi Anda disimpan langsung di memori perangkat Anda (Local Storage), bukan di server kami.

3. Layanan Pihak Ketiga

Kami menggunakan API dari EQuran.id untuk menyediakan konten ayat Al-Quran. Saat Anda mengakses ayat, perangkat Anda akan terhubung ke server mereka.

Catatan: Kami tidak bertanggung jawab atas kebijakan privasi layanan pihak ketiga tersebut.

4. Keamanan

Karena data disimpan di perangkat Anda, keamanan data sepenuhnya bergantung pada keamanan perangkat yang Anda gunakan.
