Privasi Anda adalah prioritas kami. MurajaahQu berkomitmen untuk melindungi informasi Anda dengan transparansi penuh sesuai dengan kaidah amanah.

Data yang Kami Kumpulkan

  • Data Lokal: Informasi hafalan dan progres kuis disimpan secara lokal di perangkat Anda.
  • Informasi Perangkat: Kami mengumpulkan data teknis anonim untuk optimasi aplikasi.
  • Cookies: Digunakan untuk mengingat preferensi tema dan pengaturan pengguna.
"Kami tidak menjual, memperjualbelikan, atau mengalihkan informasi pribadi Anda kepada pihak luar demi menjaga kepercayaan (amanah) pengguna."

Penggunaan API Pihak Ketiga

Aplikasi ini berinteraksi dengan EQuran.id API untuk mengambil data ayat. Penggunaan data oleh API tersebut tunduk pada kebijakan privasi penyedia layanan masing-masing.

Catatan Penting:

Kebijakan privasi ini dapat berubah sewaktu-waktu mengikuti perkembangan teknologi aplikasi. Pastikan Anda memeriksa halaman ini secara berkala.

Dengan menggunakan aplikasi MurajaahQu, Anda setuju dengan pengumpulan dan penggunaan informasi sesuai dengan kebijakan ini.
